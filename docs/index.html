读取 Skill 查看源码

三个名单，三个读取位置。

待做新库

new-repositories.md：一行一个仓库。处理近期 issue，再审计实际代码；真正完成后移除。

关注旧库

followed-repositories.md：标题下放子列表，允许重合。扫描合并去重，从上次时间接续，不重复全审计。

未完成事项

unfinished.md：公开链接和一句原因。真正解决后移除；评论、review 和 CI 实时读取。

read-positions.md 保留 GitHub 通知位置和关注库扫描时间；邮箱位置单独保存在私密的 mail-position.md。 时间、原生 ID、修订值和边界 ID 精确保留。读到不等于解决。

处理真实工作，不复制交互数据库。

完整分页获取实际 issue、PR 和讨论，遵守目标仓库规则，调查、修复、验证并完成获授权的提交。 未完成事项先保留链接和原因，再推进读取位置；部分抓取失败保留原位置。

通知、邮箱和开放工程巡检保持各自已有边界。一个执行者串行写入，不自动创建协调者、子任务或调度层。

关注和历史贡献不代表维护权限。私密邮箱、安全材料和凭据不进入公开状态； 未获授权不合并、关闭、发布、删除或推送上游。未知和未提交数据保持原样。

Direct Markdown state. No custom runtime scripts.

Three lists: new repositories, named overlapping followed groups, and unfinished links with one-line reasons. Three read positions: GitHub Notifications, followed-issue time, and a private mailbox position.

Use existing provider and file tools directly. Scan the deduplicated followed union once. Advance only after complete capture and handling or retention; a partial failure preserves the position. Read discussions, reviews and CI live. Historical contributions never imply maintainer authority.
