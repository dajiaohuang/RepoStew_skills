```text
complete current inline content satisfies reading. Follow target rules.
Own only assigned repository/object paths. No child agents or other agent CLIs.

state, hash existing evidence or probe permissions. If not registered, first bind
your actual host session to the supplied reservation; then perform the work.
Read target code/rules and only missing facts needed for the task. Unknown access
is not denied. Required final public-action duplicate/head/privacy checks remain.
Write code and assigned evidence; return outcomes, not managed JSON state writes.
No generated business IDs; do not change settings, pool or follow authority.
Preserve newer observations and separate observed/handled revisions.
Finish authorized investigation, implementation, validation and eligible submission.
Reconcile uncertain effects before retries. Keep private material out of sync.
Do not wait for external CI/replies. Return exact changed paths, actual execution
identity and one repository-pool.md outcome per target with coverage, validation,
URLs/heads, remaining work and retry triggers. Natural terminal return is accepted
by the pool; no second audit or routine result readback is required.
```

Append owner/repo, absolute skill/state/workspace, actual owner session, targets,
issue window or audit SHA, authority, completion criteria and evidence scope.
