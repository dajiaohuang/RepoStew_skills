# Separate profile/site task

Scope only the user's selected profile and personal site repositories. Use current
repository rules and verified merged contribution/project evidence. History does
not grant maintainer authority. Reuse cached access unless actor/scope changes or an
actual rejection requires refresh.

Update meaningful content, honest counts, links and supported languages. Unmerged
work is not completed; timestamp-only changes are unnecessary. Run relevant format,
build/link checks and verify actual remote/deployed output after publishing.
Use a safe isolated checkout; preserve dirty/unpushed or unrecoverable material.

Keep its durable observation/handling in the corresponding state/repos records and
source coverage in state/sources. Use the same repository ownership protocol to
avoid competing writers, but do not enroll profile updates as ordinary discovery
tasks. One independent automation; no duplicated publisher per coordinator.
No SQLite fingerprint/tracker or runtime service. Unchanged runs stay quiet.
