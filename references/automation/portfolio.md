# Daily portfolio lane

Read SKILL.md, event-maintenance.md, state.md, maintaining-owned-repositories.md
and ephemeral-storage.md completely. Scope is only the two personal repositories
bound in the host prompt. Check current permissions/default branch/instructions,
README/site content, recent verified merged PRs/projects and deployment state.
HTTP 200 is only reachability, not evidence of current or complete content.

Make minimal meaningful updates for completed contributions, genuine project/status
changes or stale links. Do not inflate counts, include unmerged work as completed,
or make timestamp-only refreshes. Complete English; complete Chinese where supported.
Verify mandatory format/build/link checks and remote head/deployment after pushing.
Use registered jobs for edits. Direct-push release must use the supported no-PR
recovery path; never fake PR evidence. Preserve and report blocked release resources.
No unrelated profile redesign, releases, secrets or permission changes.
Maintain an evidence fingerprint in SQLite so unchanged days stay quiet. A merge
may mark portfolio dirty; the daily lane decides whether it merits publication.
