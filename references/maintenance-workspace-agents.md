# Workspace entry template

Preserve unrelated user safeguards. Replace only the RepoStew wrapper:
```markdown
# RepoStew workspace
Read [workspace-root]/RepoStew_skills/SKILL.md and select coordinator or repo.
Canonical state: [workspace-root]/state, ordinary files. Read file-state.md and
state-sync.md. No runtime service, fallback database, legacy environment gate
or implicit migration. Existing legacy campaigns elsewhere stay untouched.
Use file_state.py and native owner/repo/object identities. Coordinator owns
pool/acceptance; leaf only assigned targets. Actual model config is not a prompt.
Stable prefix, dynamic assignment last, fresh repo context and same-repo deltas.
Keep skill/state/config/evidence workspace-local. Preserve follow/maintenance
authority, dirty/unknown data, credentials and recovery. Git backup is private,
reviewed, single-writer and never a distributed lock. No implicit cleanup,
merge/close/delete/release authority.
```
